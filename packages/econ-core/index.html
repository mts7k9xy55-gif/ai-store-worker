何を売っているか

現時点の Econ は「完成した経営 OS」ではありません。起業家が最初に詰まる 事業コア、会社形態、資本金、初回収益の作り方を、高速に決めるための founder-facing intake layer です。

向いている人

  • 作りたいものはあるが、最初の顧客像が曖昧な人
  • 法人設計と販売導線を同時に前に進めたい人
  • アイデアではなく、最初の収益仮説で意思決定したい人

返すもの

  • 事業コアの一文
  • 初回販売の順番
  • 最初の paid action に必要な不足情報

購入から何が起きるか

  1. Founder intake で回答を埋める

  4. 24時間以内に founder memo と next action を返す
